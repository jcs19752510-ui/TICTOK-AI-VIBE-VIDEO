# AI바이브생활팁 시리즈 기획 (1~30편)

작성: 2026-10-14. 상태: **초안(사용자 확인 전)**. 1·2편은 제작 완료(2편은 무음 시안), 3~10편은 이번에 대본과 재현 영상을 만들고, **11~30편은 가안이다**(제작할 때 다시 확정).

## 기획 원칙
- 채널 콘셉트: "코딩 몰라도 앱 만든다 / AI 활용법 + 바이브코딩 꿀팁 / 일 줄이는 AI 활용법". 타겟은 AI 초보 일반인·직장인·코딩 초보(20~50대).
- 1편 = 1핵심 메시지, 핵심은 항상 **1단계 / 2단계 / 3단계**, 끝에 "다음 편 예고"와 댓글 키워드(프롬프트 템플릿).
- 앞 2초 후킹은 **편마다 다른 패턴**(질문형, 반전형, 결과 선공개형, 공감형)을 돌려 쓴다. 바로 앞 편과 같은 패턴을 연속하지 않는다.
- **영상에서 실제로 시연할 수 있는 것만 쓴다.** 특정 서비스의 메뉴명·요금제·기능은 "확인 필요"로 두고, 대사에는 "AI 대화창"처럼 일반 표현을 쓴다.
- **이번 주 틱톡 인기 키워드·사운드는 확인하지 못했다**(틱톡 접속 불가, 사용자 확인 없음). 트렌드를 근거로 한 주제는 없다. 사용자가 확인한 키워드가 있으면 주제 순서를 바꾼다.
- 구독자·조회수 같은 수치와 "100만" 같은 표현은 영상·설명글에 쓰지 않는다(DEC-044).
