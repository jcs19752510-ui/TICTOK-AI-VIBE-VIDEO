[2026 틱톡 기조 반영 규칙]
1. 사람 냄새: 얼굴 영상은 내가 직접 촬영하고 목소리도 직접 녹음한다(화면 오른쪽 아래 원형 얼굴). 앱 화면은 실제 녹화가 아니라 "재현 화면"이다.
2. 재현 화면 구간에서는 실제로 겪은 일처럼 들리는 경험 단정 표현을 쓰지 말 것. 금지 예: "제가 직접 해봤더니", "저도 막혔어요", "처음엔 저도 헤맸어요". 대신 "~해 보겠습니다", "~하면 됩니다"로 쓴다
3. AI 사용 투명성: 앱 화면이 재현이라는 점을 설명글에 한 줄 밝힌다. AI 음성은 쓰지 않는다(본인 목소리). 영상 우상단 "재현 화면" 배지는 쓰지 않는다
4. 대사 문체: 30대 한국인이 듣기에 자연스러운 말투. "~해요/~줘요/~볼게요"의 반복으로 로봇처럼 들리게 하지 말고 "~됩니다/~합니다/~보겠습니다" 중심의 또렷한 설명 어투로 쓴다. 번역투와 AI가 쓴 티가 나는 문장은 뺀다
5. 시리즈 설계: 끝에 "다음 편 예고"(3/30)를 넣고, 앞에 1편과의 연결 문장을 넣을 것
6. 후킹은 앞 2초에 배치. 후킹 문구는 근거 없이 단정하지 말 것
7. 3단계 구성: 핵심은 반드시 "1단계 / 2단계 / 3단계"로 쪼갤 것. 단계 이름은 저장해서 따라 하기 좋게 한 줄로. 아래는 초안이며 더 좋은 구성이 있으면 이유와 함께 제안하되, 영상에서 실제로 시연할 수 있는 것만 쓸 것
   - 초안 1단계: 안 되는 것·바꾸고 싶은 것을 한 문장으로 말하기
   - 초안 2단계: 원하는 모양이나 동작을 구체적으로 말하기 (예: "할 일마다 마감 날짜를 적게 해줘")
   - 초안 3단계: 고친 뒤에 원래 되던 기능(추가·체크·삭제)이 그대로 되는지 다시 눌러 확인하기
8. 댓글 유도 CTA: "댓글에 '앱고치기' 남겨 주시면 프롬프트 템플릿을 드리겠습니다" 형태로 끝낼 것. 템플릿 본문도 같이 작성할 것 (전달은 내가 따로 처리)

[영상 규격]
- 길이: 60~90초, 9:16 세로, 1에피소드 = 1핵심 메시지
- 장면 길이 3~5초, 전환은 빠르게, 소리 없이 봐도 이해되도록 큰 자막 필수
- 구성: 후킹 2초 → 공감 5초 → 3단계 핵심 → 요약 5초 → CTA 5초
- 배경음악(BGM)은 쓰지 않는다. 효과음은 최소로, 쓸 거면 어느 장면인지 표에 적는다
- 장면별 대사는 "장면 길이(초) × 5.5음절" 안에 들어가게 쓴다. 장면마다 음절 수를 표에 함께 적는다
- 화면 배치: 자막 오른쪽에 원형 얼굴, 화면 맨 아래와 오른쪽 가장자리(틱톡 버튼 영역)는 비운다
