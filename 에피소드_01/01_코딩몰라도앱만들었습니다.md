## C. 전체 나레이션 대본

이거 코딩 몰라도 만들었어요.

앱은 코딩해야 만드는 줄 아셨죠? 제가 직접 말로만 시켜봤어요.

1단계. 만들고 싶은 걸 그냥 말로 적어요. 어려운 말 필요 없어요. 평소 말하듯 부탁하면 돼요. 그러면 AI가 앱의 레시피, 그러니까 코드를 써줘요.

2단계. 눈으로 직접 눌러보기. 미리보기 화면에서 제 손으로 눌러봤어요. 추가, 체크, 삭제요. 어, 삭제 버튼이 안 눌려요. 처음엔 저도 막혔어요.

3단계. 안 되는 걸 그대로 말해요. 삭제 버튼이 안 눌려요, 라고 적었어요. 그랬더니 고쳐서 다시 줬어요. 이번엔 잘 지워지네요.

참, 개인정보나 비밀번호는 AI에 넣지 마세요.

정리할게요. 말로 적고, 눌러보고, 안 되면 그대로 말하기.

댓글에 앱만들기 남기면 프롬프트 템플릿 드려요.

다음 편은 만든 앱 고치는 법! 팔로우하세요.

## F. 촬영·편집 가이드

- **화면 녹화 구간**: 장면 1, 4, 5, 7, 8, 10, 11. 세로 비율로 크롭할 것을 감안해 녹화 전 창 크기를 좁게 맞추기
- **확대 부분**: 입력창(장면 4, 10), 누르는 버튼(장면 7, 8), 전후 비교(장면 11)
- **BGM**: 가볍고 밝은 비트, 나레이션 뒤에서 작게. 인기 사운드는 없음(이번 주 확인 못 함). 상업 이용 가능 여부 확인 필요
- **자막 스타일**: 한 화면 두 줄 이내, 굵은 고딕, 핵심 단어만 민트색 강조. 소리 없이 봐도 이해되도록 모든 나레이션을 자막화
- **편집 속도**: 장면 3~5초, 컷 전환 빠르게. 1단계·2단계·3단계는 큰 숫자 슬라이드로 구분
- **얼굴 노출**: 필수 아님. 손과 화면 녹화 위주
- **막힌 장면(장면 8)**: 실제로 막힌 순간을 녹화한 것만 사용. 연출이 필요하면 "재현 장면" 자막을 넣을 것

3. 만든 뒤에 내가 눌러서 확인해야 할 항목을 체크리스트로 알려줘.
4. 개인정보, 비밀번호, API 키는 코드에 넣지 않도록 해줘.

[안 되면 이렇게 말하기]
