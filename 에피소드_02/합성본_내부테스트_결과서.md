## 1. 개요
- 테스트 대상: 사용자가 두 번째로 촬영해 올린 `에피소드_02/영상/두번째촬영영상.mp4`(가로 1920×1080, 101.97초)로 만든 2편 합성본

- 테스트 유형: 합성 + 자동 검수(12항목) + 재생 확인 + 소리-대본 대조(Whisper) + 음성 시험

## 2. 테스트 범위 및 제외 범위

- 제외 범위와 사유

  - **재현 화면 동작과 말의 동기화**: 2편 플레이어는 1편 초기처럼 동작 시각이 고정값이다(7절). 측정·보정하지 않았다

  - 실제 mp4의 브라우저 직접 재생: 환경 한계(H.264/AAC를 재생하지 못함, 변환본으로 대체)

## 8. 리스크 및 잔존 이슈
- **재현 화면 동작과 말이 맞지 않을 수 있음(미확인)**: 2편 플레이어는 앱 화면 동작 시각이 기획 때 정한 고정값이다. 1편에서는 이 방식으로 소리와 화면이 최대 약 1초 어긋났고, 말에 맞춰 시각을 연결(DEC-040)한 뒤에 사용자가 "싱크가 다 맞는다"고 확인했다. **2편은 이 보정을 하지 않았다.** 사용자가 영상을 보고 어긋남을 알려 주면 1편 방식(`cues.json`)으로 보정할 수 있다
- **얼굴이 작음**: 가로 촬영이라 원형(270px) 안의 머리 높이가 약 105px(원 높이의 약 40%). 얼굴 확대 크롭은 사용자 선택 전이라 하지 않았다
- **소리가 먹먹할 수 있음(귀 확인 필요)**: 저·중음이 1편보다 13~20dB 강하고 고음은 상대적으로 약하다(가슴 핀 마이크 추정). 이퀄라이저는 적용하지 않았다
- **자막과 실제 말이 다를 수 있는 곳**: Whisper 기준 장면 11("하나라도"→"하나도"), 15(댓글 키워드 "앱고치기"→"고치게"), 16("해결법"→"해결 보니다"). 인식 오류일 수 있으나 자막은 대본 그대로 들어가 있어 사용자가 확인해야 한다
- **일부 음절 인식 누락**("앱", "삭제", "비밀번호" 등): 인식기 오류인지 실제로 안 들리는지 구분하지 못함(귀 확인 필요)
- **문구 선택 전**: 제목·설명글·해시태그·썸네일 문구는 사용자 선택 전(`02_문구_20년차기준.md`). 썸네일 이미지는 아직 없다
- 합성본이 기존 무음 시안과 같은 폴더 아래 `합성본/`에 있어 파일 이름(`ep02_caption.srt`)이 시안 쪽과 겹치지만 폴더가 달라 덮어쓰지 않았다
