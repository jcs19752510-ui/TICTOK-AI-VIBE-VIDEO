## 1. 개요
- 테스트 대상: 사용자가 올린 `에피소드_05/최종영상/5번째_촬영영상.mp4`(HEVC 1920×1080, 회전 −90(세로), 118.27초, 17.28MB)로 만든 5편(앱 꾸미기) 합성본
- 합성 방법: B(한 파일 자동 분할). 얼굴 원형 크롭(`FACE_Y` 기본 0.35), 소리 −16 LUFS 정규화, 노이즈 제거·이퀄라이저 없음, 영상 우상단 배지 없음(DEC-041), 위치정보 제거. 공통 플레이어(`공통제작도구/player.html`)의 재현 화면 16장면에 합성
- 테스트 유형: 촬영본 분석 + 합성 + 자동 검수(12항목) + 재생 확인 + 소리-대본 대조(Whisper small) + 눈 검수
- 적용 Tier: Standard. 병렬: Whisper 설치와 촬영본 분석, 문구 작성(에이전트 3개)과 합성을 동시에 실행

## 2. 테스트 범위 및 제외 범위
- 범위: 장면 분할(16개), 합성 규격, 소리 위치·음량, 대본 일치, 얼굴 원형 배치, 하단 안전 영역, 위치정보, 재생
- 제외: **소리를 귀로 듣는 평가**(불가능), 얼굴 표정·입모양 싱크의 눈 검수(정지 프레임만 확인), 틱톡 업로드·라벨(사용자 몫), 노이즈 제거(필요 없다고 판단: 잡음 바닥 −46.9dB, 말 −24dB 안팎)

## 3. 테스트 환경
