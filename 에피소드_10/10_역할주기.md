**화면에 보여줄 실제 입력 프롬프트 예시** (재현 화면에 그대로 타이핑하는 문장)

- 예시 ① (장면 5, 1단계): `너는 친절한 선생님이야. 엑셀 함수가 뭐야?`
- 예시 ② (장면 7, 2단계): `친절한 선생님이야. 처음 배우는 직장인에게 엑셀 함수를 설명해 줘.`
- 예시 ③ (장면 10, 3단계): `친절한 선생님이야. 처음 배우는 직장인에게 엑셀 함수를 세 줄로, 예시 하나 포함해서 설명해 줘.`
- 예시 ④ (장면 11, 안 될 때, 가정 시연): `대상을 신입 직원으로 바꿔서 다시 알려 줘.`

**3단계 구성 점검**: 이 3단계(역할 정하기 → 상황과 대상 알려 주기 → 형식 정하기)는 제안이며 모두 영상에서 시연할 수 있다. 질문(엑셀 함수가 뭐야?)과 두 답은 가상의 예시이고 일반적인 문장만 썼다. 3단계의 형식 지정 프롬프트(③)는 장면 10의 비교 화면에서 결과로 보여 주고, 입력 장면은 따로 두지 않았다.

## F. 촬영·편집 가이드

- **재현 화면 구간**: 장면 1, 3, 5, 7, 8, 10, 11은 화면 녹화가 아니라 `공통제작도구/player.html`로 그린 목업이다. 영상 우상단 "재현 화면" 배지는 쓰지 않는다. 설명글(D) 마지막 줄로 표기한다.
- **확대할 부분**: 입력창(장면 5, 7, 11), 답변 말풍선(장면 3, 8), 두 답 비교(장면 1, 10)
- **자막 스타일**: 한 화면 두 줄 이내, 굵은 고딕, 핵심 단어만 민트색. 모든 나레이션을 자막화한다. 자막 폭 590px, 오른쪽 옆에 얼굴 원(지름 270px)을 둔다.
- **편집 속도**: 장면 2~5초, 컷 전환 빠르게. 1·2·3단계는 큰 숫자 슬라이드로 구분한다.
- **음성·소리**: 사용자 본인 목소리. 배경음악 없음. 효과음 없음. 말 속도는 임의로 바꾸지 않고, 말이 길면 그 장면 시간을 늘린다(총 60~90초 확인).
- **녹음 팁(1편 경험 반영, DEC-037·042)**: ① 장면 사이 2초 쉬기 ② 마이크 또는 이어폰 마이크를 입에 가깝게 ③ 방 소음(에어컨, 냉장고)을 끄기 ④ 틀리면 파일 안에서 다시 읽지 말고 그 장면만 따로 녹음.
- **얼굴 촬영 시 주의점**: 폰 세로 촬영, 얼굴을 화면 위쪽 1/3에 두면 원 안에서 잘림이 적다. 촬영 설정에서 위치 정보(GPS)를 끈다. 배경에 우편물·간판·가족 얼굴·명찰이 보이지 않게 한다. 의상의 글자가 보이면 공개 영상이므로 확인한다.
- **실제 AI 답을 보여줄 때**: 화면에 계정명, 이메일, 이전 대화 목록의 개인 내용이 보이면 가린다. 이 시안의 질문과 답은 가상의 예시라 해당하지 않는다.

- [ ] **틱톡 크리에이티브 센터·검색창 추천어**에서 오늘 인기 키워드·사운드 확인 (이 환경에서 접속 불가)
- [ ] **해시태그 분류**(대형/중형/소형)를 틱톡 검색창에서 확인
- [x] **AI 생성물 표시**: AI 음성은 쓰지 않는다(본인 목소리). 재현 화면은 설명글 마지막 줄에 표기했다. 틱톡 앱의 "AI 생성 콘텐츠" 라벨 설정은 업로드할 때 사용자가 확인한다(**확인 필요**).
- [x] **이전 편과 겹치는 표현 점검**: 의도한 반복: 3단계 구조, CTA 형식, 개인정보·비밀번호 문구, 7편의 "형식 정하기"와 같은 개념(7편은 요약, 이번 편은 역할). 새로 쓴 것: 후킹(질문형, 두 답 나란히), 데모(엑셀 함수 질문), "역할 → 상황 → 형식" 구조.
- [x] **경험 단정 표현 점검**: "제가 직접", "저도", "해봤더니", "헤맸" 등이 대사·자막·설명글에 없다(자동 검증).
- [x] **과장 표현 점검**: "무조건", "100%", "누구나", "1분", "클릭 한 번" 없음(자동 검증).
- [x] **개인정보·키**: 대사 장면 13에 한 줄 포함. 질문과 답은 가상의 예시이며 이름·경로·키가 없다.
- [ ] **시연 재현 가능성 점검** (같은 시연을 영상에서 실제로 재현할 수 있는지)

  | 시연 | 재현 방법 | 점검 결과 |
  |---|---|---|
  | 두 답 비교(장면 1, 10) | 같은 질문을 역할 없이, 역할을 주어 각각 물음 | 실제 AI 답은 매번 다름, 촬영 전 확인. 이 환경에서 실제 AI로 시험하지 못했다. 이 영상의 두 답은 일반적인 문장으로 쓴 가상 예시다. 역할을 주면 항상 답이 좋아진다고 단정하지 않는다 |
  | 역할 주기(장면 5) | 프롬프트 ① | 실제 AI 답은 매번 다름, 촬영 전 확인. 역할 문구에 따른 답의 차이는 확인 필요 |
  | 상황·대상 알리기(장면 7, 8) | 프롬프트 ② | 실제 AI 답은 매번 다름, 촬영 전 확인. 현재 영상은 재현 화면이라 영향이 없다 |
  | 형식 정하기(장면 10) | 프롬프트 ③ | 세 줄·예시 포함 요청을 AI가 얼마나 지키는지는 매번 다름, 촬영 전 확인 |
  | 안 될 때(장면 11) | 가정 시연 | 실제 발생을 보증하지 않고 "안 맞으면"으로 가정형으로 썼다 |

- [x] **대사 문체**: "~됩니다/~합니다/~보겠습니다" 중심. "~해요/~줘요/~볼게요" 반복 없음(자동 검증). 소리 내어 읽어 보고 어색하면 알려 달라(귀로 확인할 수 없다).
